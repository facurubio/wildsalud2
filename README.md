# wildsalud2

Monorepo de WildSalud.

## Estructura

```
apps/        Aplicaciones desplegables (web, api, mobile, ...)
packages/    Código compartido entre apps (ui, config, utils, tipos, ...)
tooling/     Configuración compartida de herramientas (eslint, tsconfig, ...)
docs/        Documentación del proyecto
.github/     Workflows de CI/CD
```

## Requisitos

- Node.js >= 20
- pnpm >= 9

## Primeros pasos

```bash
pnpm install
```
